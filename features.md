# Paperlyte Features

Discover all the powerful features that make Paperlyte the perfect choice for your documentation needs.

## Core Features

### Markdown Support
Write your documentation using familiar Markdown syntax with full support for:

- **Headers** and **emphasis**
- Lists (ordered and unordered)
- Code blocks with syntax highlighting
- Tables and blockquotes
- Links and images

### Lightweight Architecture
- Minimal system requirements
- Fast startup and rendering
- Small footprint
- No heavy dependencies

### Cross-Platform Compatibility
- Works on Windows, macOS, and Linux
- Web-based interface accessible from any browser
- Mobile-responsive design

## Organization Features {#organization}

### Hierarchical Structure
Organize your content with nested folders and automatic navigation:

```
docs/
├── project/
│   ├── overview.md
│   └── architecture.md
├── user-guide/
│   ├── installation.md
│   └── configuration.md
└── api/
    └── reference.md
```

### Automatic Navigation
Paperlyte automatically generates:
- Table of contents for each page
- Navigation menus based on folder structure
- Search functionality across all documents

### Tagging and Categorization
- Add tags to documents for easy filtering
- Organize content by categories
- Cross-reference related documents

## FAQ {#faq}

### Common Questions

**Q: Is Paperlyte free to use?**
A: Yes, Paperlyte is open source and completely free for both personal and commercial use.

**Q: Can I migrate from other documentation tools?**
A: Yes, we provide migration guides for popular tools like GitBook, Notion, and Confluence.

**Q: Does Paperlyte support team collaboration?**
A: Absolutely! Paperlyte includes features for team editing, version control, and review workflows.

**Q: Can I customize the appearance?**
A: Yes, you can use built-in themes or create custom CSS to match your brand.

**Q: Is there a hosted version available?**
A: While Paperlyte is primarily self-hosted, we're working on a cloud version for teams who prefer managed hosting.
